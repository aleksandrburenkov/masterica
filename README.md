# Арт-студия «Корни» — веб-платформа

Публичный сайт, запись на мастер-классы, магазин авторских работ, онлайн-курсы,
личный кабинет и административная панель для творческой студии «Корни» (Брянск).

Проект развивает существующее Laravel-приложение: публичный интерфейс на Blade,
админка на Filament. Отдельного SPA/сборщика нет — CSS и JavaScript лежат в `public/`.

## Стек

| Компонент | Версия |
| --- | --- |
| PHP | 8.3 |
| Laravel | 13 |
| Filament | 5 |
| БД (локально) | MySQL (`masterica_db`) |
| Blade / нативный JS | — |

## Требования

- PHP 8.3+ с расширениями `pdo_mysql`, `mbstring`, `openssl`, `fileinfo`, `gd` (по возможности);
- Composer;
- MySQL (в OSPanel — база `masterica_db`, пользователь `root` без пароля по умолчанию);
- Node.js не требуется для работы сайта (Vite используется только стандартными скриптами Laravel и не задействован публичными страницами).

## Локальный запуск

```bash
composer install
copy .env.example .env        # Windows; при необходимости поправьте DB_*
php artisan key:generate
php artisan migrate --seed
php artisan storage:link
php artisan serve             # http://127.0.0.1:8000
```

В OSPanel сайт открывается по домену проекта (например `http://masterica`);
`asset()` подставляет хост запроса автоматически.

### База данных, миграции и сиды

- Миграции: `php artisan migrate`.
- Полный набор данных: `php artisan migrate:fresh --seed`.
- `DatabaseSeeder` запускает:
  - `SettingsSeeder` — контакты, цены и правила студии (редактируются в админке);
  - `CatalogSeeder` — техники, мастер Ирина Буренкова, 4 направления, 8 будущих сеансов
    (даты считаются от даты запуска), 3 товара с вариантами и остатками, 1 онлайн-курс
    (6 модулей, 18 уроков), 2 авторских материала;
  - `DemoSeeder` — **только вне production**: демо-аккаунты, демонстрационная запись,
    заказ, доступ к курсу и синтетические демо-отзывы (помечены `is_demo`).

## Функциональность

### Публичная часть
Главная, «О студии», «Как проходят занятия», «Контакты», «Выездные мастер-классы»,
каталог мастер-классов с фильтрами, страница занятия с записью, магазин и карточка
товара, корзина и оформление заказа, каталог курсов и страница курса, отзывы,
авторские материалы, локальный лендинг «Мастер-классы в Брянске», поиск.

### Запись на мастер-класс
Сервер повторно проверяет публикацию сеанса, цену, число мест и правила дублирования.
Резерв места атомарный (блокировка строки сеанса в транзакции), поэтому последнее место
нельзя подтвердить дважды. Статусы записи и оплаты хранятся отдельно; локальная запись
подтверждается сразу, оплата — «в студии».

### Магазин и заказы
Корзина в сессии, серверная проверка цен/вариантов/остатков при оформлении, снимки
названия, варианта, SKU, цены и валюты в строках заказа. Склад ведётся append-only
движениями (поступление, резерв, освобождение, списание, корректировка); резерв
уменьшает доступный остаток, но не физический.

### Онлайн-курсы
Программа по модулям, бесплатный preview-урок, серверная проверка доступа к платным
урокам, прогресс, локальная «тестовая оплата» администратором (без реального списания),
отзыв доступа с указанием актора и причины.

### Видеоотзывы
К текстовому отзыву можно приложить видеофайл через поле с перетаскиванием
(drag-and-drop), которое также открывает выбор файла по клику, либо указать
ссылку на внешнее видео. Оставлять отзывы могут только авторизованные
пользователи; всё проходит модерацию.

Загруженные видео проверяются на вирусы, трояны и другие вредоносные вложения:
если установлен ClamAV (`VIDEO_CLAMAV_ENABLED`), выполняется полная проверка
файла, иначе используется встроенная эвристика (сигнатура видеоконтейнера,
поиск внедрённых исполняемых файлов, скриптов и полиглотов). Подозрительные и
заражённые файлы изолируются и не публикуются.

Сценарий сознательно простой и **без очереди/воркера**: проверенный файл лежит
в каталоге ожидания, а решение принимает модератор в админке:

- **Одобрение** — файл переносится в каталог видео и при необходимости
  оптимизируется (ffmpeg, H.264/AAC `+faststart`) — только если он крупнее порога
  `VIDEO_COMPRESSION_TRIGGER_KB`; создаётся обложка, видео появляется в карточке.
- **Отклонение** — видео удаляется мгновенно и безвозвратно, текстовый отзыв
  остаётся (как будто видео и не было).

Файлы хранятся в отдельном приватном каталоге `storage/app/private/reviews/*`
(входящие, видео, постеры, карантин), разносятся по годам и месяцам, а метаданные
(размер, длительность, разрешение, контрольная сумма SHA-256, статус проверки и
модерации) — в таблице `review_videos`. Доступ к файлу выдаётся только через
маршруты `/otzyvy/{review}/video` и `/otzyvy/{review}/poster` с проверкой прав
(опубликованное видео видят все, остальное — автор и сотрудники) и поддержкой
частичных запросов (HTTP Range).

В карточке отзыва видео отдаётся лениво (`preload="none"`) с обложкой; при запуске
показывается тематический прелоадер («Арт-студия Корни»), а после загрузки он плавно
исчезает и воспроизведение стартует автоматически. Одновременно играет только
один ролик, список отзывов пагинируется — поэтому даже много видеоотзывов не
замедляют сайт.

### Личный кабинет
Профиль и контакты, предстоящие и прошедшие записи, купленные курсы и прогресс,
заказы и статусы. Пользователь видит только свои данные (Laravel Policies).

### Административная панель (Filament)
Расписание, заявки и записи на мастер-классы, мастера и техники, создание мастер-класса, товары, варианты и склад,
заказы, курсы, модули, уроки, доступы и прогресс, отзывы (модерация), публичный
контент и SEO, пользователи и роли, журнал аудита. Dashboard показывает содержимое
локальной базы и предстоящие сеансы. Панель закрыта для клиентов (`canAccessPanel`).

Настройки студии (контакты, цены, правила отмены и оплаты) редактируются на странице
**Настройки студии** (только владелец).

### Заявки с сайта

Заявки разделены по источнику, чтобы менеджеры видели их в своих разделах:

- **Заявки → Выездные мастер-классы** — форма на странице «Выездные мастер-классы»
  (`outreach_requests`). Маршрутизация и расчёт удалённости не менялись.
- **Заявки → Мастер-классы** — записи на мастер-классы (`bookings`), включая
  нижнюю форму «Оставить заявку» на страницах сайта и форму на странице
  мастер-класса. Нижняя форма создаёт запись на выбранный сеанс, удалённость для
  стационарных мастер-классов не рассчитывается. В таблице есть колонка «Рассылка»
  с согласием клиента на новости студии.
- **Форма контакты** — отдельный раздел с обращениями из формы на странице
  «Контакты» (`contact_requests`): имя, телефон, email, сообщение, источник и согласия.

Все формы сохраняют обязательное согласие на обработку персональных данных и
необязательное согласие на рассылку (`consent_data`, `consent_marketing`), а также
источник отправки. Это же правило применено к регистрации, оформлению заказа,
записи на мастер-класс, отзывам и профилю. При миграции старые обращения с
направлением «Вопрос со страницы контактов» переносятся в «Форма контакты».

### Расчёт удалённости выездного мастер-класса

Калькулятор на странице «Выездные мастер-классы» добавляет к стоимости наценку за
километраж от офиса. Механизм состоит из четырёх частей:

1. **Настройки** — координаты офиса (`studio.latitude`, `studio.longitude`) задаются
   в админке: **Настройки студии → Студия и контакты**. Они же используются картой на
   странице «Контакты».
2. **Тарифы** — интервалы километража и наценка за участника хранятся в таблице
   `distance_tariffs` и редактируются в админке: **Настройки → Тарифы удалённости**
   (`DistanceTariffResource`). Пустое поле «До, км» означает открытый интервал
   «от указанного значения и далее». Пока расстояние меньше первого «От», наценки нет,
   поэтому город остаётся без надбавки.
3. **Передача данных на страницу** — `OutreachController::index()` отдаёт в Blade
   координаты офиса и всю сетку тарифов (`DistanceTariff::frontendRows()`) в
   `data-office-lat`, `data-office-lng` и `data-distance-tariffs`. Отдельный API-запрос
   не нужен: JS считает всё автономно.
4. **Определение адреса и расчёт** — `public/js/site/modules/outreach-distance.js`
   после паузы в поле «Место проведения»:
   - запрашивает координаты у серверного `/geokod` (`GeocodeController`). Контроллер
     использует активный ключ **API Геокодера** и не отдаёт его в браузер; результат
     кэшируется на сутки;
   - если серверный геокодер недоступен, пробует `ymaps.geocode` (JavaScript API),
     затем OpenStreetMap/Nominatim;
   - считает расстояние от офиса через `ymaps.coordSystem.geo.distance` (или по формуле
     гаверсинуса, если API недоступен);
   - выбирает тариф, кладёт километраж в скрытое поле `distance_km` и сообщает
     калькулятору событием `outreach:distance`;
   - `initOutreachCalculator()` в `public/js/site/app.js` пересчитывает итог:
     база + процент за участников + наценка за удалённость × число участников.

Сервер повторно считает тот же итог в `OutreachCalculator::calculate()` по
`distance_km` из формы (тариф ищет `DistanceTariff::forDistance()`), сохраняет
`distance_km` и `distance_surcharge_cents` в заявке. Если расстояние дальше последнего
интервала, применяется самый дальний тариф; если адрес определить не удалось, наценка
равна нулю и расстояние проверяет менеджер.

В `.env` используются два ключа:
- `YANDEX_MAPS_API_KEY` — JavaScript API: карта студии, подсказки адреса, JS-геокодер;
- `YANDEX_GEOCODER_API_KEY` — API Геокодера: серверное определение координат.

Если ключи не заданы или запрос к Яндексу отклонён (например, ограничением по IP),
координаты определяются через OpenStreetMap, поэтому калькулятор продолжает работать.

## Тесты

```bash
php artisan test
```

Тесты используют SQLite (`:memory:`) и проверяют: публичные страницы, авторизацию,
разграничение данных между пользователями, денежные расчёты, атомарность записи
(последнее место), статусы, права на уроки, идемпотентность выдачи доступа,
доступ к админке и загрузку всех ресурсов/страниц Filament.

## Файлы и хранилище

- Публичные ассеты: `public/css/site/*`, `public/js/site/*`, `public/images/*`, `public/fonts/*`.
- Шрифты подключены локально из `fonts/` (Gotham Pro, Als Schlange Sans) — внешние CDN не используются.
- Изображения взяты из каталога `images/` проекта.
- Платные материалы курсов предназначены для приватного диска (`storage/app/private`, `FILESYSTEM_DISK=local`);
  постоянные публичные ссылки на них не выдаются.
- Видеоотзывы хранятся на приватном диске в отдельном каталоге
  `storage/app/private/reviews/` (`videos`, `posters`, `incoming`, `quarantine`)
  и выдаются только через серверный маршрут с проверкой прав.
- `php artisan storage:link` — если понадобится публичный диск.

## Фоновые процессы

Очереди и почта в локальной версии не требуют внешних сервисов:
`QUEUE_CONNECTION=database`, `MAIL_MAILER=log`. Уведомления моделируются внутри
приложения (интерфейс + журнал). Реальные email/SMS, платёжные шлюзы, аналитика и
телеметрия не подключены.

Обработка видеоотзывов **не использует очередь и не требует воркера**: проверка,
а затем оптимизация выполняются в момент действия (загрузка/модерация). Поэтому
отдельный процесс-воркер для сайта не нужен, и на продакшене дополнительно ничего
запускать не требуется.

Служебная команда (только для обслуживания, не обязательна):

- `php artisan videos:process` — страховка: публикует видео отзывов, которые уже
  одобрены, но по какой-то причине ещё не обработаны;
- `php artisan videos:process --rescan-quarantine` — повторная проверка
  изолированных файлов (возврат после ложного срабатывания);
- `php artisan videos:process --prune-quarantine` — очистка карантина.

Если `ffmpeg` не установлен, оптимизация пропускается: видео публикуется как есть,
а сценарий остаётся рабочим.

## Переменные окружения

Ключевые переменные — в `.env.example`. Значимые для локального запуска:
`APP_URL`, `APP_LOCALE=ru`, `DB_*`, `FILESYSTEM_DISK`, `QUEUE_CONNECTION`, `CACHE_STORE`,
`SESSION_DRIVER`. Денежные суммы хранятся целыми числами в копейках, время — в UTC
с отображением в часовом поясе `Europe/Moscow`.

## Ограничения локальной версии

- Данные (цены, расписание, отзывы, профили) — локальные и демонстрационные.
- Демо-отзывы помечены как `demo` и исключаются из production-сида.
- Юридические страницы содержат демонстрационные тексты и не являются офертой.
- Публикация в production, реальные платежи и рассылки требуют отдельного разрешения владельца.
